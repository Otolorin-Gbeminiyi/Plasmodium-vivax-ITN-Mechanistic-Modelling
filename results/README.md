# Results

No fitted result tables were created as part of preparing this GitHub repository, and none are included.

After a verified run using authorised original input data, selected derived result tables and diagnostic summaries may be deposited here if the data custodian has approved their release. The R script currently writes several CSV diagnostic and summary files to the working directory; review them individually before committing. In particular, date-level outputs can contain observed trial counts.

Do not publish the 200-refit checkpoint (`refit_checkpoint.rds`) or other embedded input data without explicit authorisation; the checkpoint stores the input observation tables and fit configuration.
