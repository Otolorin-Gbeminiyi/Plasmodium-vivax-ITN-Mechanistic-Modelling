# Figures

This folder is a placeholder for selected reproducible figures. No figures were generated or supplied for this repository package.

The R script generates model-fit, profile-likelihood, residual, scenario and uncertainty visualisations as PNG files in the working directory or in the 200-refit output directory. Only add figures that have been validated against the manuscript and cleared for public redistribution. Keep file names, captions and figure references consistent with the manuscript or supplementary information.
