# Upload this project to GitHub

1. Create the repository `Pvivax-ITN-Mechanistic-Modelling` under your GitHub account.
2. Keep it **Private initially** if code/data-sharing or collaborator approvals are still pending. Make it Public only once cleared.
3. Download the GitHub-ready ZIP and **extract** it on your computer.
4. Open your GitHub repository > **Add file** > **Upload files**.
5. Upload the **contents** of the extracted `Pvivax-ITN-Mechanistic-Modelling` folder, **not the ZIP file itself**. Make sure the `scripts/` directory, `README.md`, `CITATION.cff`, and `.gitignore` are present.
6. If GitHub reports conflicts with an existing README or .gitignore, you can edit/replace those existing files with the provided contents. Do not accidentally overwrite unrelated work.
7. Commit the changes, and open `scripts/Chapter6_Mechanistic_Modelling.R` to check the complete code displays normally.
8. Before making the repository public, re-check every uploaded file for data-sharing restrictions, personal paths or sensitive content. GitHub's web uploader is **not protected** by `.gitignore`.
9. When the manuscript code is final, create a tagged release (for example `v1.0.0`) and optionally archive it in Zenodo for a DOI. Update the citation metadata and manuscript code-availability statement with the real links.

**Note:** The GitHub repository has not been created or populated by this package; this is a prepared local copy for upload.
